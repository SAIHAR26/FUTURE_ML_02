# 🎫 Support Ticket Classification System

## 📌 Overview
This project is an AI-powered Support Ticket Classification System developed as part of the Future Interns Machine Learning Internship.

The system uses Natural Language Processing (NLP) and Machine Learning to automatically classify customer support tickets and assign priority levels.

A professional Streamlit web interface was also developed for real-time ticket analysis and prediction.

---

## 🚀 Features

✅ Customer support ticket classification  
✅ NLP-based text preprocessing  
✅ TF-IDF vectorization  
✅ Machine Learning prediction model  
✅ Priority level detection  
✅ Interactive Streamlit web application  
✅ Ticket category prediction  
✅ Data visualization with graphs and charts  
✅ User-friendly dashboard UI  

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib
- NLP
- TF-IDF Vectorization

---

## 📊 Machine Learning Model

Model Used:
- Multinomial Naive Bayes

Accuracy Achieved:
- 94%

---

## 📂 Dataset

Dataset Used:
- Customer Support Tickets Dataset (200K Records)

Dataset includes:
- Ticket descriptions
- Categories
- Priority levels
- Customer support metadata

---

## 💻 Web Application Features

The Streamlit dashboard allows users to:

- Enter customer support issues
- Predict ticket categories
- Detect ticket priority
- View graphical analytics
- Explore ticket distribution charts
